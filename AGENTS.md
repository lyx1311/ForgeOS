# Context Management Rules

- Try your best to keep active conversation context below 50%, Before context becomes large:
  1. Summarize current progress.
  2. Record important decisions in docs/state.md.
  3. Compact the conversation.
- Do not keep obsolete debugging logs in context.
- Prefer reading state files instead of relying on previous chat history.
- Maintain:
  - current goal
  - completed tasks
  - pending tasks
  - important constraints
  - architecture decisions
